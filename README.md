# 🌱 GeoEcoReport

## Plateforme web intelligente de signalement des incidents urbains et environnementaux géolocalisés

GeoEcoReport est une plateforme web permettant aux citoyens de signaler des incidents urbains et environnementaux à l'aide d'une interface simple, moderne et géolocalisée.

La plateforme permet également aux techniciens et administrateurs de gérer, suivre et traiter les incidents signalés.

Un assistant intelligent **GeoEco Assistant** aide à analyser les incidents, proposer une catégorie, suggérer une priorité, générer un résumé et proposer une action adaptée.

---

## 🎯 Objectif du projet

L'objectif de GeoEcoReport est de faciliter :

- 📍 Le signalement géolocalisé des incidents
- 📸 L'ajout de photos aux signalements
- 🗂️ La classification des incidents
- 🚦 La gestion des priorités
- 👨‍🔧 L'affectation des incidents aux techniciens
- 🔄 Le suivi de l'état des incidents
- 💬 Les commentaires
- 🔔 Les notifications
- 🗺️ La visualisation sur une carte interactive
- 🤖 L'analyse intelligente avec GeoEco Assistant
- 📊 La supervision et les statistiques

---

## 👥 Types d'utilisateurs

### 👤 Citoyen

Le citoyen peut :

- Créer un compte
- Se connecter
- Signaler un incident
- Ajouter une description
- Ajouter une localisation
- Ajouter une photo
- Choisir une catégorie ou laisser l'assistant la proposer
- Consulter ses incidents
- Modifier ses incidents
- Consulter le statut de ses signalements
- Ajouter des commentaires
- Recevoir des notifications
- Utiliser GeoEco Assistant

### 👨‍🔧 Technicien

Le technicien peut :

- Consulter les incidents qui lui sont affectés
- Consulter les détails d'un incident
- Voir la localisation de l'incident
- Modifier le statut
- Ajouter des commentaires
- Suivre les interventions
- Marquer un incident comme résolu

### 👨‍💼 Administrateur

L'administrateur peut :

- Consulter tous les incidents
- Gérer les utilisateurs
- Gérer les catégories
- Affecter les incidents aux techniciens
- Modifier les statuts
- Gérer les commentaires
- Consulter les statistiques
- Superviser les fonctionnalités IA
